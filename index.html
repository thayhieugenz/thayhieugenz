Cấu hình kết nối & Đồng bộ Supabase (Chuẩn bị Deploy)

Nhập Supabase Project URL và Anon Public Key để lưu cấu hình đồng bộ cho bảng profiles, kiểm tra trạng thái kết nối thực tế tới REST endpoint của Supabase và sao chép mã SQL khởi tạo bảng ngay trước khi deploy.

Chưa cấu hình
Xem mẫu SQL khởi tạo bảng trên Supabase (profiles + app_backups) 
-- Bảng 1: danh sách hồ sơ (xem nhanh trên Supabase)
create table if not exists public.profiles (
  id text primary key,
  username text unique not null,
  full_name text not null,
  email text default '',
  phone text,
  grade text,
  dob text,
  note text,
  provider text default 'form',
  role text default 'student',
  password text default '',
  class_position text default '',
  status text default 'pending',
  reject_reason text default '',
  created_at text,
  updated_at timestamptz default now()
);

-- Nếu bảng profiles đã có từ trước, chạy thêm 3 dòng này:
alter table public.profiles alter column email drop not null;
alter table public.profiles drop constraint if exists profiles_email_key;
alter table public.profiles add column if not exists password text default '';
alter table public.profiles add column if not exists class_position text default '';
alter table public.profiles add column if not exists updated_at timestamptz default now();

-- Bảng 2: sao lưu TOÀN BỘ dữ liệu (tài khoản + cài đặt + pop-up + bật/tắt chức năng)
create table if not exists public.app_backups (
  id text primary key,            -- 'main' = bản mới nhất; 'hist-...' = bản lịch sử
  data jsonb not null,
  user_count int default 0,
  device text default '',
  updated_at timestamptz default now()
);

alter table public.profiles enable row level security;
alter table public.app_backups enable row level security;

-- Ứng dụng dùng anon key nên cần cho phép anon đọc/ghi 2 bảng này
create policy "anon_all_profiles" on public.profiles
  for all to anon using (true) with check (true);
create policy "anon_all_app_backups" on public.app_backups
  for all to anon using (true) with check (true);

-- Cấp quyền cho vai trò anon (bắt buộc với dự án Supabase mới)
grant usage on schema public to anon;
grant select, insert, update, delete on public.profiles to anon;
grant select, insert, update, delete on public.app_backups to anon;

Sao lưu & đồng bộ toàn bộ dữ liệu lên Supabase

Lưu toàn bộ dữ liệu (tài khoản, cài đặt, pop-up chào mừng, bật/tắt chức năng) vào bảng app_backups. Có thể đẩy lên, kéo về máy khác và khôi phục từ các bản lịch sử. Cần chạy SQL ở khung phía trên trước khi dùng.
